# Сборка распознавания речи

В контейнере используется исходный чекпойнт GigaAM v3 e2e CTC и стандартный загрузчик GigaAM. Положите файлы `v3_e2e_ctc.ckpt` и `v3_e2e_ctc_tokenizer.model` в `speech/model-cache/`. Сборка сверяет SHA-256 обоих файлов. Модель не хранится в Git.

На ноутбуке исходные файлы сохранены в `~/.cache/voice-todo/gigaam-sber-2026-11-09/`. Перед сборкой на новом VPS перенесите их в его `speech/model-cache/`.

```bash
docker compose up -d --build --wait speech
```


Перед распознаванием удаляются длинные участки почти цифровой тишины с сохранением 300 мс по обе стороны речи. Порог ниже одного шага PCM16: тихие слова и обычные паузы не должны отбрасываться. Фоновый шум может помешать такому ускорению; это не полноценная модель VAD.

В логах `speech_timing` видны длительность исходного и обработанного аудио, декодирование, подготовка, ожидание очереди, распознавание и число фрагментов. Аудио и текст в этот журнал не записываются. Если `queue_ms` большой, сервис занят другой записью; если `processed_s` близко к `audio_s`, тишина не была удалена.
